# Точки запуска

Текущее воспроизведение: `../solution.ipynb` (v11, платформа 0.914682).

- `quality_v11.py`: обучение и локальные абляции признаков и трудных кандидатов.
- `rank_features_v11.py`, `quality_model_v11.py`: новые признаки и их применение.
- `package_v11.py`, `verify_v11.py`, `validate_v11.py`: переносимый архив,
  независимый запуск на CPU без сети и проверка CSV.
- `polish_solution_notebook.py`: разовая структуризация итогового notebook;
  сохранённый файл уже готов к запуску.

Ниже перечислены вспомогательные скрипты прежних версий; их не требуется
запускать, чтобы получить текущий ответ.

- `validate_current.py`: формат answer.csv, исходные идентификаторы и SHA-256.
- `package_current.py`: архив основной версии с зависимостями для inference.
- `verify_current.py`: реальный Run All в свежей папке, CPU, сеть отключена.
- `run_validation_notebook.py`: исполнение выбранного notebook с сохранением вывода.
- `export_query_encoder_candidate.py`: полная рецептура encoder + ранкер v7.
- `query_encoder_rank.py`: шесть OOF encoder и сравнение обучаемого ранкера.
- `query_encoder_pilot.py`: контрастивное обучение и encoder-эксперименты.
- `bootstrap_ranking.py`: загрузка прежних компонентов из archive/notebooks/solution_v0.3.ipynb.

Остальные скрипты относятся к экспериментам и прежним версиям. Их старые команды
генерации/экспорта не следует запускать как обновление основного решения.
Исторические генераторы могут ссылаться на прежнее расположение notebooks.
`build_query_candidate_notebook.py` обновлён для нынешнего основного notebook;
его явный запуск перезаписывает notebook по сохранённой рецептуре v7.

Часть обучающих файлов входит своим SHA-256 в идентификаторы кэшей. При переносе
проекта их содержимое сохранено. Если меняем алгоритм, изменение идентификатора
и повторное обучение соответствующих моделей ожидаемо и необходимо.

Скрипт `organize_project.py` — запись разового переноса, не обычная команда
запуска: повторное применение к уже упорядоченному проекту не требуется.
