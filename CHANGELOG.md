# История версий

## v0.2.0 — обучаемый отбор кандидатов

- Ветка `feature/learned-candidate-selection`; поиск и scoring категории не изменены.
- HistGradientBoostingClassifier, 32 признака; 4 000 запросов для обучения.
- OOF-признаки в трёх группах с исключением текстов запросов и положительных item_id.
- Выбраны 120 деревьев, 15 листьев; смешивание рангов с baseline поровну (RRF).
- Development Recall@50: 0.867143 → 0.904286.
- Прежний holdout Recall@50: 0.891190 → 0.917857.
- Новый audit, 600 запросов: 0.898333 → 0.923333; прирост +0.025000.
- Парный bootstrap 95% для прироста audit: [0.006667; 0.043333].
- Финальное переобучение на OOF-признаках 6 000 запросов после фиксации параметров.
- Отдельные артефакты и отчёты в `artifacts/learned-selection-v1/`.
- SHA-256 ответа: `2847384387581912033850f8973619d5e75bbae60863a45ea1e32d49b75cf674`.

## v0.1.0 — воспроизводимый лексический baseline

- Ноутбук с загрузкой данных, анализом, валидацией и формированием ответа.
- BM25 заголовков и полных текстов, символьный TF-IDF заголовков.
- Мягкие географические признаки и подкатегории по похожим запросам из train.
- Раздельные development и holdout по 700 запросов.
- Development Recall@50: 0.8671428571.
- Holdout Recall@50: 0.8911904762; полнота объединённого пула: 0.9714285714.
- `answer.csv`: 2 452 запроса, по 50 уникальных ID.
- Полный повторный расчёт без кеша дал побайтово одинаковый ответ.
- SHA-256 ответа: `6431d618d4e22179fb2d8dd1363d8ee0c7c2d472d66392574ca735b2b69a7695`.
