## Что отправлять

На платформу загружается только `answer.csv` версии v11. Его SHA-256:
`8ce7401347beb1806f962ae1e72999fa93c89201b1044cd2433494f50e837d7e`.
Для ссылки на код предоставьте `deliverables/avito_v11_solution.zip` через
доступное проверяющему хранилище. В архиве находятся notebook, локальные веса,
модули, документация и этот же CSV. Исходные Parquet-файлы в архив не входят.
Большие веса и архив не хранятся в GitHub из-за размера.

## Воспроизведение

1. Распакуйте архив v11 и положите рядом с `Avito.ipynb` три исходных файла:
   `train.parquet`, `benchmark_queries.parquet`, `benchmark_items.parquet`.
2. Установите зависимости из `requirements.txt` и выполните notebook целиком
   через **Restart Kernel → Run All**.
3. Notebook создаёт `answer.csv` и сверяет его SHA-256 с манифестом. Ему не
   нужны внешние API; проверка выполнялась также на CPU с отключённой сетью.

Краткое описание данных, признаков, обучения, валидации и ошибок:
[эксперименты v11](docs/EXPERIMENTS_V11.md). Предыдущий каскад и его
абляции: [эксперименты v10](docs/EXPERIMENTS_V10.md). Код обучения новых
признаков и ранкера находится в `.development/quality_v11.py`, а применение
выбранной модели — в `.development/quality_model_v11.py`.
