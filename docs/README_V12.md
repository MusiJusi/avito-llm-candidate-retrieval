# Avito: решение v12

Кандидат на финальную отправку. Подтверждённая метрика v11 на платформе:
Recall@50 = 0.914682. В локальной оценке v12 улучшил matched Recall@50
с 0.961181 до 0.962225. Платформенная метрика v12 пока неизвестна.

В архиве находятся `solution.ipynb`, конфигурация, код, локальные веса,
сохранённые векторы, `answer.csv` и документы. Чтобы получить тот же CSV:

1. Распакуйте архив.
2. Положите рядом с `solution.ipynb` исходные `train.parquet`,
   `benchmark_queries.parquet` и `benchmark_items.parquet`.
3. Установите пакеты из `requirements.txt` и выполните notebook целиком.

Notebook сохраняет корневой `answer.csv` и проверяет его
SHA-256 `f4d83da229b9099fbe2e7725158987bf87bc7c1f68ccafb5c7c3c0e7b2d99fe8`.
Внешний API для выполнения не нужен. Данные, признаки, обучение, валидация и
ошибки описаны в `docs/EXPERIMENTS_V12.md`; полный обзор исходного каскада —
в `docs/SOLUTION.md`.
